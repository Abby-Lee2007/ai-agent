# ==========================================================================
#  账单导入模板（复制这个文件，改完再用 /import 导入）
#
#  三步：
#    1. 把下面「可直接编辑区」的示例行换成你自己的账单内容
#    2. 另存为 UTF-8 编码的 .txt
#    3. 回到 Agent 执行：/import 你的文件完整路径
#       例如：/import C:\Users\me\Desktop\my_bill.txt
#
#  三种写法都支持，可以混用：
#    A) 商户和金额同一行，金额放行尾
#    B) 商户+金额一行、时间单独一行（微信/支付宝导出的原始排版）
#    C) 标准日期开头，如 "2026-10-12 10:05 星巴克咖啡 -38.00"
#
#  约定：
#    · 金额为负是支出；带 + 号、或出现"退款/收入/工资"字样的算收入
#    · 以 # 开头的行会被忽略，可以放心写注释
#    · 账单抬头、合计、应还金额这类行会自动忽略
#    · 不写年份时按账单里的年份（或当前年份）推断
#
#  参考：微信/支付宝账单原样粘贴是这样，也能直接粘进 Agent：
#    抖音电商商家   -148.72
#    10月14日13:11
#    微信红包-发给何心熠   -2.50
#    10月14日08:47
#    转账-退款   +6.50
# ==========================================================================
